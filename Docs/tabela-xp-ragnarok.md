# Tabela de EXP de base do Ragnarok (pré-Renewal) — referência

Guardada para decidirmos depois a curva de XP do jogo. Fonte: iRO Wiki Classic
(https://irowiki.org/classic/Base_EXP_Chart). Valor = XP para passar do nível indicado ao
próximo, personagens normais (há coluna própria para transcendentais e tabela de EXP de Classe).

Hoje o jogo usa `CharacterStats.ExpToNext = 50 + nível² × 10` e o lobo dá 30 de XP.
Opções conversadas: usar a tabela exata, uma versão escalada (ex.: ÷10) ou a curva só até um
nível máximo menor — em qualquer caso, reequilibrar o XP dos monstros.
