# Créditos de assets de terceiros

Este arquivo registra a origem e a licença de todo asset externo usado no projeto.
Alguns exigem atribuição obrigatória — manter esta lista atualizada é requisito de licença,
não cortesia.

- **Uso no projeto:** `Medieval.fbx` é o personagem jogável (Player_Knight), com rig e animações

- **Origem:** https://poly.pizza/bundle/Ultimate-Modular-Women-Pack-aCBDXDdTNN
